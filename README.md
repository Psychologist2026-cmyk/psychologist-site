# PSYSpace — сайт для психолога

Готова демо-версія сайту українською мовою.

## Є всередині
- Головна
- Про психолога
- Послуги / ціни
- Сертифікати
- Відгуки
- FAQ
- Контакти
- Політика конфіденційності
- Кабінет клієнта
- Кабінет психолога
- Telegram-кнопка
- Демо-запис
- Демо-календар доступних годин
- Заготовка під LiqPay / ПриватБанк

## Що не підключено
Реальна оплата, Google-вхід, база даних, справжня адмінка, надсилання email/SMS і реальні повернення коштів.

## Що замінити
Замінити https://t.me/USERNAME на Telegram психолога.
Також замінити PSYSpace, Імʼя Психолога, email, телефон, тексти, ціни, сертифікати та фото.
