PSYSpace Stable Master v1

Це master/stable збірка, зібрана як один фінальний варіант без проміжних конфліктних патчів.

Всередині:
- одна фінальна логіка: final-stable-master.js;
- один фінальний дизайн-шар: master-polish.css;
- очищено старі patch-скрипти, які могли конфліктувати;
- Google login через redirect у тій самій вкладці;
- фото психолога стискається і зберігається;
- сторінка “Про психолога” у широкій двоколонковій компоновці;
- активна вкладка меню;
- послуги розбиті за типами;
- типи консультацій редагуються психологом;
- звичайний запис показує години тільки з наступного дня;
- терміновий запис автоматично обирає термінову консультацію і показує години на сьогодні;
- терміновий запит може бути без часу через Telegram;
- запис → підтвердження → демо-оплата → Zoom;
- терміновий запис → підтвердження психологом → оплата клієнтом;
- кастомні меню вибору консультації/часу в стилі сайту;
- footer із соціальними іконками;
- ширші сторінки, нормальні відступи, без розриву слів по буквах.
